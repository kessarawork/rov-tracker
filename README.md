# RoV Team Tracker

แดชบอร์ดส่วนตัวสำหรับติดตามทีมที่เชียร์ใน RoV Pro League — ดึงผลการแข่งขันจาก Liquipedia
แล้วคำนวณสถิติเชิงลึกที่เว็บทั่วไปไม่มีให้ดู

## มีอะไรในนี้

| แท็บ | ตอบคำถามว่า |
|---|---|
| **ภาพรวม** | ตารางคะแนน, โอกาสเข้ารอบ (Monte Carlo), อันดับที่น่าจะจบ, นัดของทีมอื่นที่ต้องลุ้นและควรเชียร์ใคร |
| **วินิจฉัยปัญหา** | อัตราชนะแยกตามลำดับเกมในซีรีส์, ตามความยาวเกม, การปิดซีรีส์, เล่นตอนนำ/ตอนตามหลัง, เจอทีมบนกับทีมล่าง |
| **ดราฟท์ & ฮีโร่** | ฮีโร่ที่ทีมเล่นแล้วดีกว่า/แย่กว่าค่าเฉลี่ยลีก, ตัวที่ปล่อยแล้วโดนลงโทษ, ตัวที่ถูกเล็งแบนเกินค่าเฉลี่ย, ของว่างในลีกที่ยังไม่ได้ใช้ |
| **จังหวะเกม** | จัดกลุ่มฮีโร่เป็นสายเกมเร็ว/เกมยาว แล้ววัดว่าทีมชนะเมื่อคอมเร็วกว่าหรือช้ากว่าคู่แข่ง |
| **เมต้าเปลี่ยน** | เทียบสปลิตก่อนกับสปลิตนี้ ตัวไหนมาแรง ตัวไหนร่วง ของถนัดเดิมของทีมหายไปไหน และทีมตามเมต้าใหม่ทันแค่ไหน |
| **คู่ต่อไป** | ฮีโร่ที่คู่แข่งแต่ละทีมเล่นแล้วแรงที่สุด ใช้เป็นลิสต์ตั้งต้นในการดูแบน |

## วิธีใช้

ต้องมี Python 3 เท่านั้น ไม่ต้องลงไลบรารีอะไรเพิ่ม

```bash
python3 update.py
```

สคริปต์จะสร้างสองไฟล์:

- `data/stats.json` — ข้อมูลดิบทั้งหมด
- `standalone.html` — **ไฟล์เดียวจบ เปิดด้วยเบราว์เซอร์ได้เลย** (ข้อมูลฝังอยู่ในไฟล์)

ถ้าอยากเปิดเวอร์ชันแยกไฟล์ (`index.html`) ต้องเปิดผ่านเซิร์ฟเวอร์ ไม่ใช่ดับเบิลคลิก
เพราะเบราว์เซอร์บล็อกการอ่านไฟล์ JSON จาก `file://`

```bash
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```

### เปลี่ยนทีมที่ติดตาม

```bash
python3 update.py --team "KOG"
python3 update.py --team "Tenacity"
```

ชื่อทีมที่ใช้ได้: `FULL SENSE`, `Buriram United`, `KOG`, `Tenacity`, `eArena`,
`Bacon Time`, `SOLYX`, `Godji Check`, `Hydra`

### เปลี่ยนไปสปลิตอื่นหรือฤดูกาลอื่น

แก้ค่าที่หัวไฟล์ `update.py`

```python
CURRENT_PAGE  = "RoV Pro League/2027/Summer/Group Stage"
PREVIOUS_PAGE = "RoV Pro League/2026/Winter/Group Stage"
CURRENT_LABEL = "Summer 2027"
MATCHES_PER_TEAM = 16      # ปรับตามรูปแบบการแข่ง
PLAYOFF_SLOTS = 4
```

ถ้าลีกเปลี่ยนจำนวนทีมหรือรูปแบบ (เช่น เพลย์ออฟ 6 ทีม) แก้แค่ `MATCHES_PER_TEAM`
กับ `PLAYOFF_SLOTS` ตัวคำนวณที่เหลือปรับตามเอง

### รันจำลองให้ละเอียดขึ้น / เร็วขึ้น

```bash
python3 update.py --sims 60000   # แม่นขึ้น ใช้เวลานานขึ้น
python3 update.py --sims 5000    # เร็ว เหมาะกับการกดดูบ่อย ๆ
```

## เอาขึ้นเว็บให้เข้าถึงได้จากมือถือ (GitHub Pages)

1. push โฟลเดอร์นี้ขึ้น GitHub repo
2. Settings → Pages → Source เลือก `Deploy from a branch` → branch `main` → `/ (root)`
3. ไฟล์ `.github/workflows/update.yml` จะรัน `update.py` ให้อัตโนมัติทุก 6 ชั่วโมง
   แล้ว commit ข้อมูลใหม่กลับเข้า repo เอง

เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repo>/`

## ตัวเลขในหน้าเว็บมาจากไหน

- **ตารางคะแนน / สถิติทั้งหมด** — คำนวณจากผลรายเกมที่แกะจาก wikitext ของ Liquipedia
  ไม่ได้ก๊อปตัวเลขสำเร็จจากหน้าเว็บ
- **ค่าพลังทีม (rating)** — โมเดล Bradley-Terry ระดับเกม ฟิตด้วย gradient ascent + L2 regularization
- **โอกาสเข้ารอบ** — Monte Carlo จำลองทุกแมตช์ที่เหลือแบบเกมต่อเกม (Bo5)
  เพื่อให้ผลต่างเกมซึ่งเป็นเกณฑ์ไทเบรกถูกนับด้วย เรียงอันดับด้วย แต้ม → ผลต่างเกม
- **จังหวะคอม (tempo index)** — ความยาวเฉลี่ยของเกมที่ฮีโร่ตัวนั้นถูกใช้ เอา 5 ตัวมาเฉลี่ย
  นับเฉพาะฮีโร่ที่มีข้อมูลตั้งแต่ 8 เกมขึ้นไป

## ข้อจำกัดที่ต้องรู้

- ข้อมูลบน Liquipedia มีแค่ **ผลรายเกม ฝั่งแมพ ความยาวเกม พิก-แบน และ MVP**
  ไม่มี KDA, gold, เวลาเก็บออบเจกทีฟ หรือตำแหน่งบนแมพ — บทวิเคราะห์จึงหยุดอยู่ที่ชั้นดราฟท์และผลลัพธ์
- Liquipedia อัปเดตผลตามหลัง ไม่ใช่เรียลไทม์ ระหว่างแมตช์กำลังแข่งอาจยังไม่มีข้อมูล
- กลุ่มตัวอย่างเล็ก สถิติรายฮีโร่บางตัวมีแค่ 3–5 เกม ให้ดูเป็นแนวโน้ม ไม่ใช่ข้อสรุป
- **สถิติฮีโร่ไม่ใช่เหตุผลเดียวในการแบน** การแบนจริงต้องดูว่าตัวนั้นตีคอมที่เราจะเล่นไหม
  คอมเราพีคช่วงไหน ใครเล่นตัวนั้น และลำดับพิก — แท็บ "จังหวะเกม" มีไว้ช่วยคิดเรื่องนี้
  แต่ก็ยังแทนการดู VOD ไม่ได้
